# RU HART Website

The official website for RU HART (Rutgers University Helping Autonomous Robotic Technology), a student 
organization at Rutgers University developing an autonomous food-delivery robot 
in partnership with the Rutgers Food Pantry to help address student food 
insecurity.

## Overview

This site serves as RU HART's digital home base, supporting member recruitment, 
sponsor engagement, and public outreach for club initiatives. The site's outreach 
materials contributed to securing Red Bull as a sponsor and supported a Buildathon 
event that drew over 100 participants.

## Features

- **Home**: Club mission and project overview
- **Team**: Meet the members driving the project
- **Sponsors**: Current sponsors and partnership information
- **Media**: Event photos, videos, and project updates
- **Connect**: Contact and inquiry form for prospective members and sponsors

## Tech Stack

- **React**: Component-based UI
- **TypeScript**: Type-safe development
- **Vite**: Build tooling and dev server
- **CSS**: Custom styling

## Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/Nabilah2025/ruhart_website.git
cd ruhart_website
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## About RU HART

RU HART is a 20+ member Rutgers University club dedicated to building robotics 
solutions that address real-world community needs, starting with an autonomous 
robot to deliver food from the Rutgers Food Pantry to students facing food 
insecurity.
